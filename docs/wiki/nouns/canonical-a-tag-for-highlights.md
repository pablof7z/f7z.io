# canonical a-tag for highlights

A NIP-33 `a` reference in the format `30023:<pubkey>:<slug>` (e.g. `30023:fa984bd7dbb282f07e16e7ae87b26a2a7b9b90b7246a44771f0cf5ae58018f52:attention`), used instead of the present URL so highlights work across deploys; both publish and subscribe paths filter on `#a` with this value.
