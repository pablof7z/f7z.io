# NIP-AE

A nostr NIP defining agent infrastructure: agent definitions (kind 4199), agent lessons (4129), nudges (4201), attribution (14199), MCP servers (4200), and skill announcements (4202). An agent is a pubkey that derives its instruction set from its definition plus trusted lessons plus trusted human corrections.
