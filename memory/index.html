Memory.

Every repeated correction is a failure of memory, not intelligence. Say it once.

  • Every human correction is part of the specification.
  • If the same correction is needed twice, the failure is memory rather than intelligence.
  • Keep the original words and their source instead of relying only on lossy summaries.
  • Preserve reversals and their reasons; current truth without history loses important context.
  • The goal is a system that carries months of direction into the next instruction.
