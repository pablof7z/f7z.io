NIP-29 relay for creators. Group-based communication on nostr.

NIP-29 defines relay-based groups with moderation capabilities. relay29 is a reference implementation that lets creators run their own group infrastructure.

features

  • Group creation and management
  • Moderation tools (kick, mute, ban)
  • Invite-only or public groups
  • Thread support within groups
