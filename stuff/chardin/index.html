chardin.js

github

Overlay instructions for web apps. 4,900+ stars. Created 2013.

chardin.js creates overlay instructions that point to elements on your page. Named after Jacques Cousteau's famous documentarian Jean-Michel Cousteau's style of annotating underwater footage.

features

  • Simple API
  • Element highlighting
  • Customizable positioning
  • Works with any DOM structure

A legacy project from a different era, but still used in production by many applications.
