Olas

olas.app · github

Instagram-like nostr client. Photo sharing for iOS, Android, and Web.

Olas brings visual content to nostr with kind:20 picture events. It's designed to feel familiar to Instagram users while running on sovereign infrastructure.

features

  • Kind:20 picture events with proper metadata
  • Video feed with sound
  • Swipe-to-zap gestures
  • Instagram-like photo filters
  • Multi-image posts
  • NWC wallet integration
  • Remote signer support (Amber, nsecBunker)
  • Nutzaps for ecash tipping

platforms

  • iOS — Available on TestFlight
  • Android — Available on Zapstore
  • Web — olas.app

Built with NDK and ndk-mobile for cross-platform development.
