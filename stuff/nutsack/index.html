Nutsack

NIP-60/61 Cashu wallet. A wallet that lives in nostr.

home stuff now podcast feed

Nutsack implements NIP-60 (Cashu wallets on nostr) and NIP-61 (Nutzaps). Your ecash tokens are stored encrypted on relays, making them portable across any client that supports the standard.

features

  • Cashu ecash integration
  • P2PK token transfers (Nutzaps)
  • Cross-client wallet portability
  • PWA support for mobile
  • Multi-mint management
  • Transaction history on relays

how it works

  • Tokens stored as NIP-60 events (encrypted)
  • Nutzaps use P2PK locks for recipient-only redemption
  • Any NIP-60 compatible client can access your wallet
  • No central server holds your money

“Don't load too much money; this is highly experimental!”
