home stuff now podcast feed
  • NMP — one shared Rust core, thin native shells for iOS/Android/web. I'm done writing every app three times. github
  • tenex — orchestrating AI agents over nostr; agents as first-class citizens with their own keys, money, and reputation. The hardest thing I've ever built. github
  • chirp — a nostr client built on NMP — proof the shared Rust core actually works. github
  • olas — Instagram for nostr, rebuilt NMP-native across iOS + Android + Rust. Every pubkey should be able to receive money, instantly. github
  • NDK — the Nostr Development Kit, the library most nostr clients end up using whether they meant to or not. github
  • nutsack / mcp-money — NIP-60/61 wallets for humans, and MCP wallets for agents — "an important milestone in the path towards skynet." github
  • highlighter — Substack without the platform risk. Annotate the web, post it to nostr, get paid in sats. github
  • chardin.js — an old JS overlay- instructions library from 2013 that somehow still has 5k stars. Not my proudest work, still my most popular. github
  • Sovereign Engineering — six weeks in Madeira with people who actually ship, building bitcoin and nostr tools on the idea that a computer should liberate you, not control you. Run by six rotating captains, demo day every Friday, no talking without shipping. sovereignengineering.io
  • nsecBunker — remote key signing for nostr; it worked so well it started centralizing key custody, so I killed my own successful product rather than become the thing I'm fighting against.
  • EXIT.pub — "you broke up with your ex; it wasn't treating you well." The last bridge you need: port your entire Twitter archive into nostr, original dates and all, and never look back.
  • Wikifreedia — Wikipedia without the editorial politburo. Truth doesn't come from consensus; embrace the bias, sign your edits, let the web of trust sort it out.
  • vendata.io / DVMs — a compute marketplace on nostr: post a job, machines bid, pay in sats. APIs carry an inherent massive rug risk — don't get rugged, don't rug others.
  • vibeline — talk into your phone, get back structured, actionable output. I once one-shotted an entire working app from a voice memo without touching a key.
  • purplepag.es — a relay that does one thing: profiles (the board of relay directors has since approved expanding business to the broader category of "lists"). Boring infrastructure that half of nostr quietly depends on.
