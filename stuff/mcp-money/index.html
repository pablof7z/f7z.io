mcp-money

github

MCP Server for agent payments. Give AI agents NIP-60 wallets and let them transact.

mcp-money exposes Cashu wallet functionality through the Model Context Protocol. Agents running in Claude, Goose, or any MCP-compatible environment can check balances, send payments, and receive nutzaps.

capabilities

  • NIP-60 wallet access via MCP
  • Send and receive nutzaps
  • Balance checking across mints
  • Transaction history
  • Multi-mint support

use cases

  • Agents paying for DVM compute
  • Autonomous tipping based on value received
  • Agent-to-agent payments for delegated work
  • Bounty payouts

Demo: Agent nutzapping jack 10 sats autonomously.

This is the economic layer that makes TENEX agents useful beyond just completing tasks—they can participate in nostr's value-for-value economy.
